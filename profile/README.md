# BOAZ Website

> 국내 최초 빅데이터 연합동아리 BOAZ를 위한 서비스를 만드는 Product & 서비스운영팀 Organization 입니다.

BOAZ 공식 홈페이지(bigdataboaz.com)와 내부 프로덕트, 그리고 이를 뒷받침하는 AWS 인프라를 직접 만들고 운영합니다.

## Repositories

| 레포 | 설명 |
|---|---|
| [frontend](https://github.com/BOAZ-website/frontend) | React + Vite 공개 웹사이트 (www) |
| [backend](https://github.com/BOAZ-website/backend) | Spring Boot API 서버 (api) |
| [frontend_admin](https://github.com/BOAZ-website/frontend_admin) | 관리자 콘솔 (admin) |
| [product-infra](https://github.com/BOAZ-website/product-infra) | AWS 인프라 Terraform 관리 (리크루팅 시즌 트래픽 대응 포함) |

## Tech

- Frontend: React 19, Vite, TypeScript
- Backend: Java 21, Spring Boot
- Infra: AWS (EC2/CodeDeploy, S3/CloudFront, RDS, Route53), Terraform
